# fbzipper

כלי מקומי לתזמון ופרסום פוסטים בקבוצות פייסבוק שאתה חבר בהן — דרך הפרופיל האישי שלך, בקצב אנושי.

## התקנה והפעלה

```bash
npm install
npx playwright install chromium   # רק אם Google Chrome לא מותקן
npm start
```

פתח את http://localhost:3777

## שימוש

1. **דשבורד → פתח דפדפן להתחברות** — נפתח חלון Chrome נפרד; התחבר לפייסבוק פעם אחת. ההתחברות נשמרת ב-`data/browser-profile`.
2. **קבוצות** — "ייבא את הקבוצות שלי" סורק את https://www.facebook.com/groups/joins/ , או הדבק קישורים ידנית. אפשר לסמן תגיות (אזור / תחום) ולכבות קבוצות.
3. **פוסטים** — טקסט + עד 10 תמונות.
4. **קמפיינים** — בחר פוסטים וקבוצות. כמה פוסטים = רוטציה בין הקבוצות (כל קבוצה מקבלת נוסח אחר). אפשר להגדיר חזרה כל N ימים ותאריך התחלה.
5. **הפעל פרסום אוטומטי**. בלשונית **תור פרסום** אפשר גם "פרסם עכשיו" לפריט בודד — מומלץ לבדיקה ראשונה.

## כללי הקצב (לשונית הגדרות)

| הגדרה | ברירת מחדל |
|---|---|
| שעות פעילות (שעון ישראל) | 07:00–23:00 |
| מרווח אקראי בין פוסטים | 8–15 דקות (מינימום 3) |
| מקסימום פוסטים ביום | 25 (עד 60) |
| לא לאותה קבוצה יותר מפעם ב- | 24 שעות |
| עצירה בשבת ובחגים | כן — מ-30 דק' לפני הדלקת נרות ועד צאת השבת/החג (זמני תל אביב, `@hebcal/core`) |

פוסט שנכשל מנוסה שוב אחרי 30 דקות, ואחרי 2 כישלונות מסומן "נכשל" (אפשר להחזיר לתור).

## מבנה

- `src/scheduler.js` — לוגיקה טהורה: שעות, שבת/חג, מכסות, בחירת הפריט הבא, מחזורים. מכוסה בטסטים (`npm test`).
- `src/facebook.js` — Playwright על פרופיל דפדפן קבוע; פעולה אחת בכל פעם.
- `src/runner.js` — לולאה כל 30 שניות, פוסט אחד לכל היותר בכל פעם.
- `src/server.js` — API + ממשק (`public/`), מאזין רק ל-localhost.
- `data/` — `db.json`, תמונות ופרופיל הדפדפן (לא נכנס ל-git).

## חשוב לדעת

- אוטומציה של חשבון אישי מנוגדת לתנאי השימוש של פייסבוק, ופרסום אגרסיבי עלול להוביל להגבלת החשבון. התחל בנמוך (10–15 ביום) ופרסם רק בקבוצות שמתירות פרסום כזה.
- פייסבוק משנה את הממשק מדי פעם; אם הפרסום מפסיק לעבוד, הסלקטורים נמצאים בראש `src/facebook.js` (`COMPOSER`, `PHOTO_BTN`, `POST_BTN`).
- לא כלול בכוונה: הצטרפות המונית לקבוצות, שליחת הודעות המוניות במסנג'ר, ריבוי חשבונות ועקיפת זיהוי.
